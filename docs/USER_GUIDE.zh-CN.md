# 使用指南

[English](USER_GUIDE.md) · **简体中文** · [首页](../README.zh-CN.md)

## 安装与升级

从[发布页](https://github.com/Maxthonzx/AIQuota/releases/latest)下载 Apple Silicon、Intel 或 Windows 11 x64 对应安装包。Mac 打开 DMG 后将 AIQuota 拖到 Applications；Windows 先关闭 AIQuota，再运行 EXE 或 MSI。新版本可覆盖安装，应用标识和系统凭据服务名称保持一致。

应用使用系统 WebView。macOS 要求 13.3 及以上；Windows 要求 WebView2 111 及以上，安装程序可在需要时获取或更新 WebView2，此过程需要联网。当前包未签名，macOS 包未公证，系统提示处理见[常见问题](TROUBLESHOOTING.zh-CN.md)。

## 添加供应商

首次启动时，AIQuota 会带入检测到已有本机凭据的服务。之后以保存的供应商列表为准：即使全部移除，也会保留空总览，不会自动把预设重新添加回来。

点击「添加供应商」，搜索并选择预设，填写显示名称，按支持的方式连接：

- **Codex：**通过本机 Codex CLI 登录 ChatGPT，OpenAI API Key 不能代替这种订阅登录。
- **Kimi Code：**读取本机 Kimi Code 配置，或填写 Coding 订阅 Key。供应商保存后，可在配置面板中继续添加其他 Key 账号。
- **Antigravity：**安装并登录 Antigravity，保持其语言服务运行。
- **OpenCode Go：**读取本机当前 Go 账号，或填写 Go 订阅 Key。AIQuota 不会切换 OpenCode 的当前账号。
- **Cursor：**读取本机 Cursor IDE 登录。
- **GLM：**使用 Coding Plan 套餐 Key，普通按量 API Key 不适用于该订阅查询。
- **DeepSeek：**填写 DeepSeek 开放平台 API Key，查询账户余额。

Key 使用密码输入框，可切换显隐。已经保存的 Key 不会再次回显；留空即保持原值。保存失败时表单保持打开并提示错误，不会显示成功。保存成功后会立即查询额度，网络或认证错误会显示在卡片上，可重新配置。

## 配置自定义供应商

选择「自定义供应商」。同一服务可创建多个独立名称或凭据的自定义连接。

1. 填写显示名称，选择「订阅」或「API」。该分类用于筛选，不会改变远端接口。
2. 填写完整额度查询 URL，接口必须接受 GET 并返回 JSON。要求 HTTPS；本机 loopback 允许 HTTP，例如 `http://127.0.0.1:8080/quota`。
3. 选择 Bearer、API Key Header 或无需认证。Header 支持 `x-api-key`、`api-key`、`x-goog-api-key`、`Authorization`。Bearer 会自动添加 `Bearer ` 前缀，Header 模式则原样发送输入值。
4. 选择显示方式，并按响应配置字段路径。

| 模式 | 必填字段 | 含义 |
| --- | --- | --- |
| 可用余额 | 数值字段 | 显示可用余额，单位可选 |
| 已用百分比 | 数值字段 | 值应在 0–100 之间，不能直接使用 0–1 比例 |
| 已用量 / 总额度 | 数值字段和总额度字段 | 已用量不能为负，总额度必须大于 0 |

响应示例：

```json
{
  "data": {
    "balance": "12.50",
    "used": 25,
    "total": 100,
    "reset_at": "2026-11-02T08:53:16Z"
  }
}
```

余额使用 `data.balance`；用量使用 `data.used` 和 `data.total`；可选的重置时间字段为 `data.reset_at`。支持数字字符串；数组元素用数字段，例如 `data.items.0.used`。路径采用简单点号格式，不执行脚本，也不是完整 JSONPath 表达式。

重置值支持 ISO 时间字符串、秒或毫秒时间戳。时间字符串建议包含时区偏移或 `Z`，确保表示确定时刻；显示时会转换为电脑当前时区。

聊天模型地址不能当作余额接口。需要 POST、OAuth 刷新、请求签名或 JavaScript 提取的接口，需要单独实现供应商适配器，通用配置表单不支持。单次响应最多 1 MB，不跟随重定向。请把 Key 填在认证栏，勿放进 URL。

## 排序与移除

可在总览或供应商列表拖动手柄，也可在列表点击上下按钮，或聚焦手柄后按上下方向键。两处使用同一份持久化顺序；同一供应商的多个账号保持为一组。

打开供应商配置，点击「移除」并确认：

- 内置供应商移除后，隐藏相关卡片并停止额度查询。AIQuota 保存的 Key 与外部应用登录保留，可重新添加。
- 自定义供应商移除时，同时删除该连接的已保存 Key。重新添加时需重新配置。
- 删除其他 Kimi 账号会移除 AIQuota 保存的该账号/Key，不影响外部 Kimi CLI 登录。

已移除或已修改连接的旧请求结果会被忽略。错误卡片也可单独收起，供应商仍保留；成功查询后重新显示额度。

## 外观、重置时间与通知

在「设置」中选择自动、浅色或深色。默认自动跟随系统并响应系统变化；手动选择重启后仍保留。

重置时间按电脑当前时区显示，包含当地夏令时规则，格式为 `YYYY.MM.DD HH:mm:ss`，同时展示倒计时。供应商未提供有效时间时，不会编造一个时间。时间来自供应商，倒计时归零不代表远端已完成额度恢复。

自动刷新可选 1、2、5、10 分钟。恢复提醒需要系统通知权限，并在实际观察到耗尽额度恢复时发送，不是单纯在倒计时归零时发送。设置页可测试通知。应用需要保持运行才能刷新和通知。

## 隐私与存储

| 数据 | 保存位置或发送目的地 |
| --- | --- |
| 手动 Key | Windows 凭据管理器或 macOS 钥匙串；自定义连接使用独立存储项 |
| 已有 CLI/IDE 凭据 | 读取相应应用的本机数据，AIQuota 不改写其登录文件 |
| 外观、顺序、名称、URL、字段映射和提醒偏好 | 本机 WebView 存储 |
| 认证与额度请求 | 对应供应商，或你配置的自定义接口 |
| Antigravity 查询 | loopback 上的本机语言服务接口 |

AIQuota 不提供统计或遥测收集服务。已保存的 Key 不返回前端；输入时的 Key 会交给本机后端保存，查询由后端执行。

旧明文配置仅在安全存储写入并读回校验成功后删除。存储被锁定、不可用、损坏或冲突时，原配置保留并提示错误；请先解决存储问题，勿直接删除原文件。回退到 1.3 及更早版本时，旧版本无法读取新安全存储中的 Key。

如何在排错时避免泄露凭据，见[安全说明](../SECURITY.zh-CN.md)。
