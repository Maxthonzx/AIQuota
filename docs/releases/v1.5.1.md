# AIQuota v1.5.1

**English** · [简体中文](v1.5.1.zh-CN.md)

The first release from the cleaned public repository, with English-first bilingual documentation and separate native Mac downloads.

- Apple Silicon Macs: `AIQuota-v1.5.1-macos-apple-silicon.dmg` or `.app.zip`.
- Intel Macs: `AIQuota-v1.5.1-macos-intel.dmg` or `.app.zip`.
- Windows 11 x64: `AIQuota-v1.5.1-windows-x64-setup.exe` or `.msi`.
- Source snapshot and `SHA256SUMS.txt` are included.

Existing provider configuration, safe key storage, automatic/light/dark themes, local-time reset displays, and drag/up/down provider ordering are retained. The application interface remains Simplified Chinese.

macOS 13.3+ is required. Windows uses WebView2 111 or newer. Current downloads are unsigned and Mac packages are not notarized. See the [README](../../README.md) and [troubleshooting](../TROUBLESHOOTING.md) before installing.
