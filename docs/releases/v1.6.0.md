# AIQuota v1.6.0

The first stable release of the 1.6 series, tested through the v1.6.0-beta.1 and v1.6.0-beta.2 pre-releases. The previous stable release remains available as v1.5.1.

## Plan expiry on quota cards

- Quota cards can show the plan expiry time, precise to the minute in the computer's local time zone, together with the remaining whole days, which update live. Expired plans are highlighted in red.
- The expiry is filled in automatically when a provider's quota API returns it: GLM, Kimi, OpenCode and Google responses are probed for common expiry field names, and providers without such a field simply show nothing.
- Every provider accepts a manually entered expiry in its settings (copied from the provider's billing page); the manual value takes precedence over the automatic one.
- Custom providers can additionally map an optional response field path for the expiry, next to the existing reset-time mapping.

## Compact desktop skin

- Choose **Settings → Interface skin → Compact** for denser quota cards and top navigation that fit more accounts on screen; Classic remains the default.
- Reset rows show the countdown on the left with the date and time on the right; light, dark and system themes remain available.

Packages are unsigned and macOS packages are not notarized. The app keeps the same identity and local settings as previous releases: installing it replaces the previous installation while saved keys and configuration are preserved.

GitHub Actions builds Apple Silicon macOS, Intel macOS and Windows x64 packages. Please report problems with the version, platform and reproduction steps, without credentials or private account data.
