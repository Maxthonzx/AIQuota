# AIQuota v1.6.0-beta.1

This is a **beta pre-release** for testing the optional compact skin. The stable release remains **v1.5.1**; existing stable packages are retained.

- Choose **Settings → Interface skin → Compact**. Classic remains the default.
- More accounts fit on screen with top navigation and denser quota cards.
- Reset countdown appears on the left, with date and time on separate lines on the right.
- Light, dark and system theme choices remain available. Connections, credentials and query behavior are shared with the stable frontend.

Beta packages are unsigned and macOS packages are not notarized. The beta uses the same app identity and local settings as the stable app: installing it may replace the installed stable application. It does not create a parallel isolated account store. You can reinstall v1.5.1 or switch back to the classic skin; the stable GitHub downloads remain available.

GitHub Actions builds Apple Silicon macOS, Intel macOS and Windows x64 packages. See the [compact skin guide](../COMPACT_SKIN.md) for behavior and validation limits. Please report problems with the version, platform and reproduction steps, without credentials or private account data.
