# AIQuota v1.5.1

[English](v1.5.1.md) · **简体中文**

整理后的公开仓库首个发布版，提供英文默认的双语文档，并拆分原生 Mac 架构下载。

- Apple Silicon Mac：`AIQuota-v1.5.1-macos-apple-silicon.dmg` 或 `.app.zip`。
- Intel Mac：`AIQuota-v1.5.1-macos-intel.dmg` 或 `.app.zip`。
- Windows 11 x64：`AIQuota-v1.5.1-windows-x64-setup.exe` 或 `.msi`。
- 包含源码快照和 `SHA256SUMS.txt`。

保留供应商配置、Key 安全存储、自动/浅色/深色外观、本机时区重置时间，以及拖动/上下箭头排序。应用界面仍为简体中文。

要求 macOS 13.3+；Windows 使用 WebView2 111 及以上。当前包未签名，Mac 包未公证。安装前可阅读 [README](../../README.zh-CN.md) 和[常见问题](../TROUBLESHOOTING.zh-CN.md)。
