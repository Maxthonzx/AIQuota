# AIQuota v1.6.0

1.6 系列的首个正式版，经过 v1.6.0-beta.1 和 v1.6.0-beta.2 两个预发布版本测试。上一个正式版 v1.5.1 继续保留可下载。

## 额度卡片上的套餐到期信息

- 额度卡片可以显示套餐到期时间（精确到分钟，按电脑当前时区显示）和剩余可用天数，剩余天数实时刷新；到期后以红色标出。
- 到期时间在供应商接口返回时自动识别：GLM、Kimi、OpenCode 和 Google 的响应会按常见字段名探测，接口未返回的供应商不会显示该行。
- 每个供应商都可以在配置中手动填写到期时间（从套餐页或账单页抄录）；手动填写优先于自动识别。
- 自定义供应商在原有重置时间映射旁，新增可选的套餐到期字段路径映射。

## 紧凑桌面皮肤

- 在「设置 → 界面皮肤 → 紧凑」启用更密集的额度卡片与顶部导航，一屏显示更多账号；默认仍为经典皮肤。
- 重置区域左侧为倒计时，右侧日期、时间各占一行；浅色、深色及跟随系统主题保留不变。
