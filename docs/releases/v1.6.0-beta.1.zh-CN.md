# AIQuota v1.6.0-beta.1

这是用于体验可选紧凑皮肤的 **Beta 预发布版本**。**v1.5.1 继续作为正式版保留**，原有正式版下载包不会被替换。

- 在「设置 → 界面皮肤 → 紧凑」启用；默认仍为经典皮肤。
- 顶部导航与更密集的额度卡片，让一屏显示更多账号。
- 重置区域左侧为倒计时，右侧日期、时间各占一行。
- 保留浅色、深色及跟随系统；连接、凭据和额度查询沿用原有实现。

Beta 安装包未签名，macOS 包未公证。Beta 与正式版使用相同应用标识和本机配置：安装可能替换本机已有应用，并非隔离账号存储的并行应用。可重新安装 v1.5.1，或直接切回经典皮肤；GitHub 正式版下载始终保留。

由 GitHub Actions 构建 Apple Silicon macOS、Intel macOS 与 Windows x64 安装包。行为与验证边界见[紧凑皮肤说明](../COMPACT_SKIN.zh-CN.md)。反馈问题时请提供版本、平台与复现步骤，不要附带凭据或私人账号数据。
