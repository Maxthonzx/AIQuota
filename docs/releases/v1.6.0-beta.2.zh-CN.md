# AIQuota v1.6.0-beta.2

这是为额度卡片增加套餐到期信息的 **Beta 预发布版本**。**v1.5.1 继续作为正式版保留**，原有正式版下载包不会被替换。

- 额度卡片现在可以显示套餐到期时间（精确到分钟，按电脑当前时区显示）和剩余可用天数，剩余天数实时刷新；到期后以红色标出。
- 到期时间在供应商接口返回时会自动识别：GLM、Kimi、OpenCode 和 Google 的响应会按常见字段名探测，接口未返回的供应商不会显示该行。
- 每个供应商都可以在配置中手动填写到期时间（从套餐页或账单页抄录）；手动填写优先于自动识别。
- 自定义供应商在原有重置时间映射旁，新增可选的套餐到期字段路径映射。

Beta 安装包未签名，macOS 包未公证。Beta 与正式版使用相同应用标识和本机配置：安装可能替换本机已有应用，并非隔离账号存储的并行应用。可重新安装 v1.5.1；GitHub 正式版下载始终保留。

由 GitHub Actions 构建 Apple Silicon macOS、Intel macOS 与 Windows x64 安装包。反馈问题时请提供版本、平台与复现步骤，不要附带凭据或私人账号数据。
