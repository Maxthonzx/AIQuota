# 紧凑皮肤

## 使用

在「设置 → 界面皮肤」选择「紧凑」。经典皮肤仍是默认值，随时可以切回。皮肤与浅色/深色/跟随系统分别选择，偏好保存在本机 `aiquota_skin`，不迁移、不修改供应商连接或凭据。

紧凑皮肤采用绿色配色与顶部导航，1120px 窗口显示三列，640px 窗口显示两列，1600px 及以上显示四列。收紧标题、统计区与卡片间距。每个窗口的重置区左侧为倒计时，右侧日期、时间分别占一行，按电脑本机时区显示。

## 变更边界

由独立前端候选版的紧凑设计提炼而来，复用原应用全部数据与操作组件。未把候选版模拟数据、账号或演示刷新逻辑引入正式入口。供应商目录、连接表单、排序、真实刷新、通知、原生安全存储与 Rust 后端保持现有行为。皮肤不是新应用版本，也没有创建安装包或 Release。

实现：`src/skin.ts` 管理皮肤偏好，`src/compact.css` 通过根节点 `data-skin` 限定覆盖范围，`src/App.tsx` 增加设置入口并在紧凑皮肤下分行展示重置日期和时间。样式不依赖外部字体或新依赖。
